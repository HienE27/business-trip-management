# PR Discovery Report — Template

> **Mục đích**: Template chuẩn để aggregate output từ 3 discovery scripts
> (`static-analysis.sh`, `repo-analysis.sh`, `context-analysis.sh`) thành một
> báo cáo có cấu trúc. Báo cáo này là input cho buổi Candidate Review — người
> review dùng nó để quyết định các batch cleanup tiếp theo (Batch A/B/C/D).
>
> **Không sửa file này để chạy discovery**. Copy file này ra
> `docs/pr/pr<PR_NUMBER>-discovery-report.md` rồi paste output + điền phần
> "Tóm tắt" + "Quyết định".

## Appendix — Lệnh chạy lại

```bash
# Từ repo root
./scripts/discovery/static-analysis.sh > /tmp/static.json
./scripts/discovery/repo-analysis.sh    > /tmp/repo.json
./scripts/discovery/context-analysis.sh > /tmp/context.json

# Pretty-print (cần jq)
jq . /tmp/static.json
jq . /tmp/repo.json
jq . /tmp/context.json
```
